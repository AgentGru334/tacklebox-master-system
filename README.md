# Tacklebox Master System

**A Windows desktop research utility for Borderlands 4 item builds.**

[Download the latest Windows installer](../../releases/latest)

Tacklebox Master System turns save-editor item codes and item-card screenshots
into a searchable local research library. Decode and compare builds, document
testing, extract card stats with local OCR, and safely update the parts reference
when the shared workbook changes.

## Install

1. Open the latest release using the link above.
2. Download `Tacklebox.Master.System.Setup.v1.0.0.exe`.
3. Double-click the installer and follow the short setup.
4. Leave **Launch Tacklebox Master System** checked and select **Finish**.

Python, PowerShell, and administrator access are not required.

Windows SmartScreen may show **Unknown Publisher** because the first release is
not digitally code-signed. Download TMS only from this official release page and
use the supplied SHA-256 file if you want to verify the installer.

## What it does

- Captures and decodes Borderlands 4 save-editor item codes
- Organizes builds in a searchable notebook
- Compares parts and finds the closest saved match
- Records test goals, results, verdicts, notes, and history
- Stores, crops, and enlarges item-card screenshots
- Extracts card names, stats, and effects using entirely local OCR
- Creates verified backups and restores them safely
- Imports updated Tacklebox reference workbooks without losing research

## Your data stays yours

TMS does not upload item codes, builds, screenshots, OCR results, or notes. Each
Windows user starts with an empty personal library stored locally under
`%LOCALAPPDATA%\Tacklebox Master System`.

Installing a newer version preserves that library. The public installer does not
contain the developer's builds, item cards, tests, or backups.
